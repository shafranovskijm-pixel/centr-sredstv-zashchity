# Деплой в Timeweb App Platform как Frontend

Проект подготовлен для простой схемы: GitHub → Timeweb App Platform.

1. В App Platform откройте вкладку **Frontend** и выберите **Next.js**.
2. Подключите репозиторий `shafranovskijm-pixel/centr-sredstv-zashchity` через аккаунт GitHub.
3. Выберите ветку `main` и включите сборку по последнему коммиту, чтобы работал автодеплой.
4. Путь к проекту оставьте корневым.
5. Команда установки: `npm ci`.
6. Команда сборки: `npm run build:timeweb`.
7. Выходная директория: `out`.
8. Переменные окружения и команда запуска не требуются: результат является статическим сайтом.
9. После первой сборки проверьте технический домен и затем подключите основной домен.

Если мастер позволяет выбрать **HTML/CSS/JS** и вручную указать команду сборки,
можно использовать его с теми же значениями: `npm ci`, `npm run build:timeweb`,
директория публикации `out`.

## Публичные документы

Небольшие PDF, которые должны быть доступны всем посетителям, можно хранить в `public/documents/`. Например, файл `public/documents/programma.pdf` будет доступен по адресу `/documents/programma.pdf`.

Не добавляйте в репозиторий персональные данные, внутренние документы, пароли, токены, ключи и файлы `.env`. Крупные или часто обновляемые документы лучше вынести в объектное хранилище S3.
